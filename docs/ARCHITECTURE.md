\# Earl Architecture



Earl uses a layered design:



LLM / AI

↓

High-Level Goals

↓

Tasks

↓

Deterministic Skills

↓

Mineflayer

↓

Minecraft



The AI decides WHAT Earl should do.



Normal code decides HOW Earl performs actions such as:



\- movement

\- mining

\- gathering

\- crafting

\- combat

\- farming

\- building

\- survival



The LLM should not directly control movement or execute arbitrary code.
